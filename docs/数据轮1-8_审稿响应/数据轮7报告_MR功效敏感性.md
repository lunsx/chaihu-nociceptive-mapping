# 数据轮 7 报告：MR 功效与多组织敏感性（对应问题 5）

日期：2026-11-15
范围：仅跑数据，未改正文；pandas + scipy

## 一、本轮目标

量化 MR 零结果到底是"功效不足"还是"组织错配"，避免把 null 简单说成"无效应"，也避免不假思索地一律归因于低功效。

## 二、方法

- 由每个 SNP 的 F 与 eQTLGen 暴露 N（31,684）反推单 SNP R²，求和得工具总 R²。
- 用两样本非中心卡方近似（Burgess 2014）算功效曲线与 80% 功效的最小可检标准化效应（MDE），结局 ukb-b-11413 N=461,857。
- 补二分类结局敏感性（患病率 K=0.1/0.2/0.3，有效 N=4K(1−K)N）。
- 汇总 GTEx 多组织与肝 eQTL 可用性。

### 多组织与肝
- 仅 IL1B（7 组织）、TACR1（42 组织）有多组织 F≥10 工具；**7 个基因全部无肝 eQTL**。

## 四、必须诚实说明的解读（与原方案假设的修正）

1. **功效不是主要瓶颈。** 结局 N 很大，标准化效应 ≥0.05–0.08 已能高功效检出。原方案预设的"underpowered"被实际计算修正。
2. **组织错配才是主导限制。** 暴露是全血 eQTL，且无任何肝 eQTL，无法捕捉肝特异调控；多组织工具也无法补肝。
3. **结局异质性**：腹痛多病因，进一步稀释信号。
4. 正确口径：null 是"在全血工具下未检出效应"。鉴于功效充足，它对"由全血介导的较大效应"有一定反向信息，但对肝特异/小效应无信息，更不是无效应证据。
5. 连续近似与二分类敏感性均给出同方向结论；具体患病率未知，故给区间而非单点。
