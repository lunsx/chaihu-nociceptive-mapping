# 数据轮 8 报告：MD 收敛诊断与延长评估（对应问题 6/7）

日期：2026-11-15
范围：仅跑数据，未改正文；pandas + scipy，未新增模拟

## 一、本轮目标

用收敛诊断量化 10ns 双技术重复的真实状态，为"MM-GBSA 降级为相对/稳定性指标"和"只有 luteolin 有 MD 支持"提供证据。

## 二、方法

读取两条轨迹逐帧 MM-GBSA（各 125 帧），计算：累积均值 ΔG、5 块分析、自相关时间与有效样本量、半轨迹漂移，以及跨轨迹均值差与帧相关。

## 三、关键结果（真实数字）

| 指标 | 轨迹1 | 轨迹2 |
|---|---|---|
| 均值 dG | −29.08 | −31.60 |
| SD | 2.32 | 3.55 |
| 半轨迹漂移 | +1.01 | +1.57 |
| 块极差 | 1.41 | 6.85 |
| 自相关时间 τ | 1.26 | 8.39 |
| 有效样本量 | 99.0 | 14.9 |
| 累积均值起止 | −27.44→−29.08 | −27.23→−31.60 |

- 跨轨迹：均值差 2.53，帧相关 −0.058（p=0.521，无相关）。

## 四、必须诚实说明的解读（重点）

1. **未收敛。** 两条轨迹累积均值都仍向更负方向移动、半轨迹漂移为正，10ns 内未平台化。
2. **精度有限。** 跨轨迹差 2.53、帧能量零相关；轨迹2 自相关强、仅约 15 个有效样本，轨迹1 约 99 个，二者采样效率差异大。
3. **绝对值不可作亲和力。** 已知省略熵 + OBC2 负偏，对接约 −7 而 MM-GBSA 约 −29/−32，口径不同；MM-GBSA 仅用于相对/稳定性，不进摘要结论。
4. 主要结论以对接集合 + 姿态/接触稳定性为准，不以 MM-GBSA 绝对数支撑。

## 五、问题 7 的处理（零成本兜底，正文阶段执行）

- 只有 luteolin 有 MD 支持；alpha-cyperone、cyperotundone 等标注 "docking-only candidates; molecular dynamics not performed"。
- 跨结构排名按结构分别报告，不再宣称全球稳健（5KIR 与其他结构口径不一致）。

## 六、产出文件（计算分析根目录）

- `md_convergence_diagnostic.json`：双轨迹全套诊断 + 跨轨迹指标。
- `md_cumulative_dg.csv`：累积 ΔG 曲线（供后续画图）。
- 脚本 run_md_convergence.py 在 agent workspace。
