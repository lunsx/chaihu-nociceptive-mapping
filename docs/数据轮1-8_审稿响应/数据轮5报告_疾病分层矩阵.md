# 数据轮 5 报告：疾病分层证据矩阵（对应问题 2）

日期：2026-11-15
范围：仅跑数据，未改正文；pandas

## 一、本轮目标

解决"多种疾病被当作可互换证据池"。把每个基因在各数据集、各疾病实体中的方向/数值做成矩阵，只有满足严格规则才宣称跨疾病一致，并显式枚举疾病。

## 二、疾病实体与来源口径

- **代谢性脂肪肝病（MASLD/NAFLD，主疾病）**：bulk meta 合并效应、大队列 GSE281797、GSE344087 MASLD 单细胞（仅流行度，单 HC 不定方向）、小鼠 MASLD Visium（单列）。
- **胆汁淤积病（PSC/PBC，正交支持）**：16 供体单细胞疾病对比、人 PSC Visium。
- 两类疾病免疫生物学不同，禁止跨疾病直接合并。

## 三、判定规则（经三轮收紧，最终口径）

1. 小效应阈值：|Hedges g| < 0.2 视为 inconclusive，不充当方向，避免近零值制造"冲突"。
2. 检测地板：空间阳性% < 1% 视为未检出，不充当反向。
3. 每个疾病实体内部须有干净一致方向；来源冲突标 conflicting，功效不足标 inconclusive。
4. 只有两个疾病实体都给出干净且相同的方向，才判 cross-disease consistent。

## 四、关键结果（真实数字）

### 总体
- 60 个框架基因全部入表。
- 人代谢侧：36 inconclusive、14 up、10 down。
- 胆汁淤积侧：43 up、8 inconclusive、5 down、4 conflicting。
- **跨疾病一致仅 12 个基因**（不是早期宽松口径的 33 个）。

### 12 个跨疾病一致基因
- up：ICAM1、IL1A、PTGER3、SPP1、CCNA2、IL10、MMP9、ODC1、PLAU、SERPINE1
- down：HSD3B1、SREBF1

### 头条基因的诚实分类（重点）

| 基因 | 人代谢 | 胆汁淤积 | 判定 |
|---|---|---|---|
| IL1B | inconclusive（g=0.106/0.068 小） | up | 非跨疾病 |
| TNF | inconclusive（−0.081/0.094 近零） | up | 非跨疾病 |
| PTGS2 | inconclusive（−0.102/0.003 近零） | up | 非跨疾病 |
| FOS | **down（−0.545/−0.424 显著）** | up | 真冲突 |
| TRPV1 | up | down | 真冲突 |

- IL1B/TNF/PTGS2 的 bulk 效应小（与稀释、Meta 结论一致），但单细胞高流行，矩阵如实呈现"单细胞强、bulk 弱"，不强行给跨疾病帽子。
- FOS 是真正的跨疾病方向冲突（bulk 显著 down、PSC 90% up），immediate-early 基因易受解离/技术影响，正文必须正面交代。
- TRPV1 方向冲突，与"TRPV1 上调不可复现"的稳定口径一致。

## 五、必须诚实说明的解读边界

1. 阈值 0.2 是分析选择，正文会同时给出原始 g，让读者可自行判断；不把阈值当成隐藏不利结果的工具。
2. 跨疾病一致只证明方向在两类疾病中相符，不证明因果或可成药。
3. 小鼠 Visium 单列，不用于裁定人源冲突；单 HC 的 MASLD 不做疾病对比。
4. 12 这个数字偏保守，是诚实优先的结果；文稿不再使用"跨疾病汇聚"这类笼统表述。
