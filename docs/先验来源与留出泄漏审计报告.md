# 先验来源与留出泄漏审计报告

日期：2026-11-16
范围：核查留出方向预测（held-out directional prediction）所用先验方向是否独立于被评估队列；只做机械核对与口径修正，不改动任何数值。

## 一、审计问题

审稿意见 M2 指出，69.2% 本质是"已知方向复现"，要求说明固定先验与外部参照是否独立。本审计核查先验方向的真实来源，以及它与留出三队列（GSE281797、GSE260666、GSE147304）之间是否存在数据重叠。

## 二、核查方法

1. 先验方向取自 `target_list_enriched.json` 的 `direction` 字段，与 `multicohort/多队列_跨队列方向投票.csv` 的 `direction` 逐基因比对。
2. 用文件时间戳确认先后关系。
3. 解析投票脚本 `e48_multicohort.py`，确认投票由哪些符号构成。

## 三、关键发现

1. 52 个获得先验方向的基因中，仅 7 个有明确文献锚定（FOS、IL1B、PTGER3、PTGES、PTGS2、SCN9A、TRPV1），其余 45 个为框架策展方向，无独立文献字段。
2. 全部 52 个先验方向与多队列投票方向完全一致（52/52），且投票文件（2026-11-13）早于 `target_list_enriched.json`（2026-11-14），说明先验方向即多队列共识，而非独立的文献先验。
3. 投票由 2 个病例对照符号与 4 个分级相关符号构成，来源为 GSE281797、GSE260666、GSE193066、GSE192959；GSE147304 被标记为 inconclusive，不计入投票。
4. 因此：
   - GSE281797、GSE260666 的自身符号参与了先验形成，其逐队列一致率（73.1%、92.3%）不独立于先验，存在自包含。
   - GSE147304 是唯一完全留出的队列，也是真正的前瞻检验；先验只与它 42.3% 的符号相符，低于随机。

## 四、修正动作

1. 方法 2.12、结果 3.4、摘要、讨论 4.1/4.7 与结论中，把"literature-fixed / literature direction"统一改为准确表述：多队列共识方向，并显式披露 GSE281797/GSE260666 的非独立性与 GSE147304 的独立留出地位。
2. 新增两个可核查来源表：
   - `prior_direction_provenance.csv`：逐基因方向、是否文献锚定、文献编号、框架来源、依据类型。
   - `prior_cohort_independence.csv`：逐队列是否贡献先验、是否完全留出、先验一致率。
3. Figure 10 图注补充"描述性、非匹配、跨平台、无跨数据集 p 值"。
4. 数据驱动的留一队列（LOCO，55.8%，p=0.166）作为诚实的泛化结果保留并强调。

## 五、边界与结论

所有数字（69.2%、55.8%、42.3%、73.1%、92.3% 等）均未改动，修正的是其独立性与解释口径。修正后论文不再把 69.2% 表述为独立前瞻预测，而是如实呈现为多队列共识在贡献队列内的自一致，以及独立队列上不支持前瞻性泛化，避免审稿人发现隐藏泄漏。
