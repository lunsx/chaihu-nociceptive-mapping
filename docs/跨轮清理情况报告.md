### #122 SMR/HEIDI（本轮唯一新分析，阴性）

- 云主机 `mr3/smr_heidi.py`：纯 Python 实现
  - SMR：Wald 式 `b_smr = b_y / b_x`，delta 法算标准误；
  - 分析型 HEIDI（Zhu 2016）：区域 = 基因体 ±100 kb，eQTL p<0.05、上限 20 SNP、剔除与 top r²>0.9 的代理；
  - 加 fallback：top cis SNP 在某结局缺失时，按 F 降序选第一个该结局可用的 cis SNP，并记录 `instrument_snp` 与 `is_fallback`。
- 首跑 22 行（TACR1 top SNP rs2087172 在全部 4 结局缺失、PTGS2 rs689470 在 2 结局缺失），加 fallback 后重跑 **28 行（7 基因 × 4 结局）**。
- `smr_multiplicity.py`：加 Bonferroni / BH 校正列。
- **结论：28 个检验仅 1 个名义 p<0.05（PTGS2 / 上腹痛 R101，p=0.0246，且为 fallback 工具、HEIDI 不可估）；Bonferroni 阈值 0.0018 与 BH 校正后无任何 SMR 关联存活；HEIDI 可估处 p 全部 0.22–1.0，无异质性证据。** 与 MR、共定位阴性一致。
- 手工独立复算 SMR b/se 并用 scipy 双侧 p 核对一致（首轮手写误加因子 2，已用 scipy 纠正，表值正确）。

### #124 肝组织 eQTL（结构性局限，已查实）

- 对 rs689470 做 phewas（参数名 `variant`）返回 20 条关联，其中 eQTL 仅 1 条，即血液 eQTLGen；其余为肾/尿酸/代谢物等 GWAS，**未出现任何独立肝组织 eQTL**。
- 结论：OpenGWAS 不托管这些基因的肝 eQTL，唯一可查的是 eQTLGen 全血。**血液—肝组织错配是结构性局限，无法在 OpenGWAS 内消除。** 第 2 轮"肝 eQTL 无定论"到此收口为"确认无独立肝 eQTL"。
