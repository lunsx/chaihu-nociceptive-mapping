# 第 3 轮：MR（孟德尔随机化）+ 共定位正式分析报告

## 一句话结论

这轮把第 2 轮"想做但没做成"的事真正做成了：**7 个核心基因在大样本 eQTLGen（N≈3 万）里全部有合格的顺式（cis）工具变量，F 统计量全部远超 10**。但把它们拿去对"腹痛/胁痛"做因果推断，**MR 没有发现稳健的因果效应，共定位也没有发现共享的致病变异（PP.H4 全部 ≤ 0.003）**。这是一个方法做得扎实、结论诚实的"阴性结果"，和之前"CRP 对慢性痛的 MR 也是阴性"的预警方向一致。

打个比方：工具变量就像"基因彩票"，一个人天生带的某个版本会让某个炎症基因表达高一点或低一点。如果"天生表达高"真的会让人更容易腹痛，那 MR 应该能查出这个关联。结果是查不到——说明**普通人群里由天生基因决定的那部分表达差异，不怎么预测自我报告的腹痛**。这不等于炎症通路是假的，更不等于药没用，原因见第 6 节。

## 1. 这轮用的数据和接口

- **暴露（工具变量来源）**：OpenGWAS 收录的 eQTLGen 血液顺式 eQTL，欧洲人群，数据集 ID 形如 `eqtl-a-<Ensembl编号>`，hg19/GRCh37 坐标，作者 Vosa U（2018）。
- **结局（疼痛 GWAS）**：全部为英国生物样本库（UKB）欧洲人群、二分类（log odds），共 4 个，构成一个连贯的"腹痛家族"：

| 结局 | OpenGWAS ID | 总样本 N | 病例数 | 含义 |
|---|---|---|---|---|
| 胃/腹痛（近一个月） | ukb-b-11413 | 461,857 | 39,646 | **主结局**，样本最大、表型最清楚 |
| 慢性胃/腹痛（3 个月以上） | ukb-b-19097 | 38,911 | 21,711 | 慢性腹痛 |
| 上腹痛（ICD-10 R10.1） | ukb-b-6608 | 463,010 | 5,981 | 解剖位置最靠近肝（右上腹） |
| 未特指腹痛（ICD-10 R10.4） | ukb-b-6223 | 463,010 | 11,925 | 腹痛诊断 |

- **接口方式**：新版 OpenGWAS 是 **POST 优先、数组参数在 query 里重复**。令牌已验证通过（GET /user 正常，trial 标签，有效期至 2026-11-28）。
- **工具变量筛选**：p ≤ 5×10⁻⁸，经 LD 去连锁（r²=0.001、窗口 5000 kb、欧洲人群），再用 Ensembl GRCh37 基因坐标按"同染色体且距基因体 ≤1 Mb"判定 cis/trans。

## 2. 工具变量真实强度（补齐第 2 轮的缺点）

第 2 轮用免登录的小样本 GTEx 摸底，只有 TACR1 在全血有 1 个工具，当时担心"工具不够"。这轮拿到大样本 eQTLGen 后，情况完全不同。**7 个基因全部有 cis 工具，且 F 全部 ≥10**：

| 基因 | 总工具数（cis+trans） | cis 工具数 | cis 工具的 F | cis 最强 SNP |
|---|---|---|---|---|
| IL1B | 9 | 1 | 66.0 | rs6542082 |
| TNF | 3 | 3 | 599.4 / 32.6 / 29.7 | rs1121800 |
| PTGS2 | 9 | 3 | 856.6 / 415.6 / 58.1 | rs689470 |
| IL6 | 1 | 1 | 90.4 | rs10265117 |
| CALCRL | 1 | 1 | 631.3 | rs8176580 |
| TACR1 | 3 | 2 | 143.9 / 70.8 | rs2087172 |
| TRPV1 | 1 | 1 | 80.5 | rs222741 |

要点：
- 所有 cis 工具 F 都远高于 10 的弱工具门槛，**弱工具偏差（weak instrument bias）在这轮基本不构成问题**。
- 一个重要发现：`eqtl-a` 数据集里同时含 cis 和 trans 显著 eQTL。例如 IL1B 的 9 个工具里只有 1 个是 cis，其余 8 个分布在 chr17/7/14/6/5/4/8 等其他染色体。trans 工具的多效性（pleiotropy）风险高，因此**主分析只用 cis 工具，trans 仅作敏感性对照**。

## 3. MR 结果：没有稳健的因果效应

主分析用 cis 工具，主结局（胃/腹痛）结果如下（单 SNP 用 Wald 比值，多 SNP 用 IVW）：

| 基因 | 方法 | SNP 数 | 效应 beta | p 值 |
|---|---|---|---|---|
| IL1B | Wald | 1 | −0.00065 | 0.914 |
| TNF | IVW 固定 | 3 | −0.00211 | 0.285 |
| **PTGS2** | **IVW 固定** | **3** | **−0.00281** | **0.041** |
| IL6 | Wald | 1 | 0.00266 | 0.601 |
| CALCRL | Wald | 1 | 0.00172 | 0.399 |
| TACR1 | Wald | 1 | −0.00335 | 0.569 |
| TRPV1 | Wald | 1 | −0.00067 | 0.901 |

**关于 PTGS2 那个 p=0.041，必须诚实处理，不能当成"发现了"：**
1. 它只在固定效应 IVW 下名义显著，**随机效应 IVW（p=0.31）、MR-Egger（p=0.98）、加权中位数（p=0.16）全部不显著**。
2. 该基因的 Cochran Q 异质性检验 p=0.017（3 个 SNP 之间不一致），单 SNP 比值里有一个 −0.0206 的离群值在拉动结果，另两个只有约 −0.002。
3. 在另外 3 个腹痛结局上，PTGS2 全部不显著（p=0.063–0.80），**无法复现**。
4. 用 cis+trans 全部工具做敏感性分析，PTGS2 固定效应 p=0.0325，结论性质相同（依旧是脆弱的名义值）。

所以正确表述是：**PTGS2 出现一个不稳健、不可复现、被异质性和离群 SNP 驱动的名义信号，不构成因果证据**；其余 6 个基因在所有 4 个结局上均无显著效应。MR-Egger 截距在仅 3 个 SNP 时不具解释力（自由度太低），仅作记录。

**方法可靠性校验**：IVW 已用独立的"过原点加权最小二乘"交叉验证，beta 和 SE 完全一致；MR 方法模块（Wald/IVW/Egger/加权中位数/Cochran Q）为纯 Python 实现，不依赖 R。

## 4. 共定位结果：eQTL 信号很强，但疼痛 GWAS 在同区域没有对应信号

共定位问的是和 MR 不同的问题：**eQTL 和疼痛 GWAS 在 cis 区域里是不是由同一个变异驱动**（不管 MR 显不显著）。用每个基因体 ±100 kb 的区域，取两套数据的重叠 SNP（每个区域 471–1134 个），用 Wakefield 近似贝叶斯因子（ABF）计算：

| 基因 | 重叠 SNP | PP.H1（只有 eQTL 有信号） | PP.H4（共享同一变异） |
|---|---|---|---|
| IL1B | 471 | 0.911 | 0.0005 |
| TNF | 1134 | 0.967 | 0.0006 |
| PTGS2 | 521 | 0.995 | 0.0029 |
| IL6 | 738 | 0.999 | 0.0006 |
| CALCRL | 746 | 0.998 | 0.0006 |
| TACR1 | 998 | 0.998 | 0.0004 |
| TRPV1 | 850 | 0.993 | 0.0004 |

- **PP.H1 ≈ 0.91–0.999**：cis 区域里 eQTL 关联很强，但疼痛 GWAS 在同一区域几乎没有关联。
- **PP.H4 全部 ≤ 0.003**，远低于共定位常用的 0.8 门槛，**没有证据表明两者共享致病变异**。
- 已对共定位先验 p12 做敏感性网格（1e-6 到 2e-5），PP.H4 始终在 0–0.006，结论不依赖单一先验。
- 过程中修正了一个计算 bug：初版把两套 ABF 各自归一化，丢失了绝对证据量，导致 PP.H0 被错误抬高；改用 logsumexp 在 log 空间求和后结果正确。

MR 和共定位两条独立证据互相印证，结论一致：**没有找到"基因表达 → 腹痛"的共同遗传因果信号。**

## 5. 为什么"阴性"不等于"通路是假的"或"药没用"

这轮的阴性是有明确边界的，不能过度解读：

1. **结局表型太宽泛**：自我报告的"胃/腹痛"是个大杂烩，包含肠胃、消化、肌肉等各种原因，**不是肝脏特异的胁痛**。真正的肝源性疼痛在一般人群里占比很低，信号被稀释。
2. **MR 测的是"天生表达设定值"，不是"炎症现场的局部状态"**。疼痛更可能由局部组织此刻的炎症和介质（PGE2、IL-1β 等）驱动，而不是由出生就定好的 eQTL 表达水平决定。这正好和我们 #105 稀释分析、#108 Meta 检验力不足的结论呼应。
3. **冗余与代偿**：炎症通路有多条备份，单基因的 germline 变化常被其他通路补偿。
4. **检验力与样本**：部分 ICD 诊断结局病例只有几千；cis 工具少（多个基因只有 1 个 cis SNP），多 SNP 方法（Egger/中位数）在 2–3 个工具时本身就偏弱。
5. **组织差异**：eQTL 来自全血，而疼痛的终末器官（神经、肝局部）的调控可能不同。

**① 这轮做了什么**
- 验证令牌；摸清 OpenGWAS POST 优先的接口规则。
- 确认 7 个 eQTLGen 暴露数据集全部存在，拉取经 LD 去连锁的工具并完成 cis/trans 分类。
- 选定 4 个 UKB 腹痛结局，完成等位基因对齐与 harmonization。
- 纯 Python 实现并跑通 Wald/IVW 固定+随机/MR-Egger/加权中位数/Cochran Q，外加 cis+trans 敏感性分析。

- 导出 3 张 CSV（MR 结果、共定位、工具变量）和全部中间 JSON。
