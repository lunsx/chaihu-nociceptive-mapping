## 二、五个可以直接写进论文的结论

**1. 随机种子几乎不影响结果。** 同一受体/配体/打分的三次重复，平均极差只有 0.04 kcal/mol，最大 0.647 kcal/mol。也就是说，之前"只跑一个 seed 42 会不会不稳"的担心，实测下来是不成立的——问题不在种子，在结构和打分函数。

**2. 两个打分函数给出的"绝对值"不一样，但排序大体一致。** vinardo 系统性地比 vina 高 2.35 kcal/mol（范围 +0.40 到 +4.64，Wilcoxon p < 1e-4），两者的配体排序 Spearman ρ = 0.755。所以**不能跨打分函数直接比数值**，只能比排序。

**3. 跨结构的一致性只是"部分一致"。** 6 组结构两两比较里，vina 下 1CX2 vs 6COX 完全一致（ρ=1.00），1CX2 vs 3PGH 0.886（p=0.019），但 3PGH vs 5KIR 只有 0.257（p=0.62）；vinardo 下 1CX2 vs 5KIR 甚至是负相关（ρ=−0.371）。**换句话说，换一个晶体结构，配体名次可能整体重排**，这和上一轮 alpha-cyperone、"两 PTGS2 结构 ρ=0.657" 的观察一致，只是这次给出了完整的 6 组矩阵。

**4. 木犀草素不再是"最强"，塞来昔布在关键结构上明显更强。** 见下表（均值，kcal/mol；括号内为三 seed 极差）：

- 塞来昔布：在 4/8 个面板里第 1（vina 侧 1CX2、6COX 都是第 1），中位名次 1.5（vina）/2.5（vinardo）。
- 木犀草素：名次 1–3，中位 3（vina）/2.5（vinardo），**只在 5KIR 上排第 1**。
- α-香附酮：只在 3PGH 的两个打分面板里排第 1（vina 与 vinardo 都是），到 5KIR 就掉到第 5–6。

> 这条必须写清楚：**阳性对照在含共晶抑制剂的两个结构（1CX2、6COX）上比木犀草素强 1.2–3.1 kcal/mol，只在 5KIR 上被木犀草素反超 0.3 kcal/mol。** 这跟"天然产物对接分数接近甚至超过上市药"的常见写法是相冲的，诚实处理方式是把塞来昔布并列展示，说明本工作关心的是"方剂成分能否落在这个口袋里、相对次序如何"，不是"比上市药更强"。

**5. 5KIR 的口袋跟另外三个不是一回事。** 塞来昔布在 1CX2/6COX 是 −11.3/−11.5，到 5KIR 只有 −6.68；同一配体在同一个蛋白的四个构象里差 4.8 kcal/mol。这解释了上一轮"两 PTGS2 结构 ρ=0.657、对构象敏感"的来源：**不是打分噪声，是口袋形状本身不同**。论文正文原来只用 5KIR，需要在方法/局限里补一句"5KIR 为无配体占据的构象，阳性对照在该构象的得分明显偏低"。

## 三、踩到的技术坑（已解决，写进方法）

**塞来昔布的 pdbqt 让 Vina 直接崩。** 用 Meeko 按 SMILES 重建、换 obabel 重建，三次都报同一个内部错误：

```
An internal error occurred in ...\src\lib\tree.h(101)
```

试了 vina、vinardo 都一样，说明不是打分函数不支持氟原子，而是**该配体 pdbqt 的刚性树（ROOT/BRANCH 嵌套管状结构）有缺陷**：`BRANCH 4 23` 里面又出现 `BRANCH 23 26`，子分支端点超出父分支范围。

解决：改用 DUD-E 富集那轮已经跑通的临床对照 pdbqt（`C:\dockwork\dude_bench\control_pdbqt\c-1.pdbqt`，28 原子含 F3/N3/O2/S1，即塞来昔布），立刻正常出分。**教训写进方法：同一个分子不同工具产出的 pdbqt 不能混用，出分前要用一个已知阳性的配体做"能不能跑"的烟测。**

另外，smina 的 GitHub release 仍然 404，多打分改用 Vina 自带的 `--scoring vinardo`，已在方法里注明。
