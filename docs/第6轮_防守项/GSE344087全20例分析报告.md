# GSE344087 全 20 例补全分析报告（第 6 轮）

日期：2026-11-14。数据：GSE344087，人肝单细胞，**19 例 MASLD + 1 例健康对照（HC）**。

## 一、为什么能补全

上一轮只拿到 `RAW.tar` 的 170 MB 中一部分，勉强抽出 7 个完整 MASLD 样本、0 个对照，所以正文只能写"只能定位、不能对比"。

这一轮发现 **GEO 逐个样本的补充文件是单独可下的**，不需要那个 170 MB 的 tar：

```
https://ftp.ncbi.nlm.nih.gov/geo/samples/GSM9970nnn/GSM<GSM号>/suppl/
文件名  <GSM号>_<MASLD_S0xx | HC_S020>_LIVER_filtered_feature_bc_matrix.h5
单体 1.9–22.0 MB
```

逐样本映射（已核实并全部下载成功）：

| GSM | 样本 | GSM | 样本 |
|---|---|---|---|
| GSM9970276–9970282 | MASLD_S001–S007 | GSM9970283–9970294 | MASLD_S008–S019 |
| **GSM9970295** | **HC_S020（唯一健康对照）** | | |

实测速度 0.24–0.89 MB/s，13 个文件约 3 分钟。这比"断点续传 170 MB tar"稳，也比多连接 Range 并行（此前实测 0 字节）靠谱。

## 三、单例对照不能做疾病对比（诚实结论）

拿到 HC 之后第一反应是"终于能比了"，但跑出来发现比不了，原因有两条，都写进报告：

**1. 对照只有一个供体，细胞级检验是伪重复。** 19 vs 1 个供体，任何 p 值都只是在测"这个人的细胞和那 19 个人的细胞不一样"，不是在测疾病效应。所以输出表里只给供体级百分比，**没有附任何 p 值**。

**2. 这个对照的细胞组成跟 MASLD 组根本不是同一类样本。** 中位细胞占比：

| 细胞类型 | HC（1 例） | MASLD（19 例中位） |
|---|---|---|
| 肝细胞 | 0.040 | 0.016 |
| T/NK | 0.318 | 0.588 |
| 巨噬/库普弗 | 0.052 | 0.135 |
| 内皮 | 0.192 | 0.050 |
| 胆管 | 0.133 | 0.019 |
| 浆细胞 | 0.179 | 0.024 |
| 肥大 | 0.047 | 0.011 |

对照的胆管/浆细胞/内皮比例高得反常、肝细胞只有 4%，看起来是**非实质细胞富集或建库方案不同**的样本。组成都不同，逐细胞类型的百分比差就没有解释力——比如 HC 肝细胞 IL1B 20.7% 而 MASLD 只有 0.9%，方向与既有文献相反，合理的解释是批次/富集差异，而不是"MASLD 肝细胞 IL1B 下降"。

**因此维持原来的判断：这份数据能定位，不能对比。** 但理由从"没有对照"改成了"对照只有一例且组成不匹配"，这个说法更准确，也更难被审稿人挑。

## 四、对正文的影响

正文现在写的是：

> Because this subset contains no healthy control, it supports localization only and not a disease-versus-normal comparison.

需要改成（英文待末轮统一改写时定稿）：

> The full series contains 19 MASLD samples and one healthy control. The control is a single donor whose cell-type composition differs markedly from the MASLD samples, so the series supports localization across 19 donors but not a disease-versus-normal comparison.

同时把"seven MASLD samples / 10,992 cells"更新为"nineteen MASLD samples / 41,515 cells (48,594 with the control)"，并补上供体级中位数与范围（比单一数字更抗审）。
