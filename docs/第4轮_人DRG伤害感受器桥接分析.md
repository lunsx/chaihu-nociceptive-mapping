# 第 4 轮补强：人 DRG 伤害感受器桥接分析（#115）

**一句话结论**：我们在真实的人类背根神经节（DRG）单细胞数据里确认了一件事——**发炎肝脏里的免疫细胞负责"发信号"，而人身上专门报警疼痛的伤害感受器神经元负责"收信号"，而且接收 PGE2 的受体 EP3（PTGER3）就在这些痛觉神经元上大量存在**。这把"肝里的炎症"和"人感觉到胁痛"在人体细胞层面接上了；但这仍是"接得上"的证据，不是"药已经止住痛"的证据。

---

## 1. 这一轮要回答的问题

前几轮的证据链停在"肝里有炎症介质"，但审稿人会追问：**这些介质凭什么能让人痛？痛觉神经元上有没有对应的"接收天线"？**

- 肝脏侧（已完成）：免疫细胞（巨噬/单核）产生 IL1B、TNF、IL6；PTGS2（COX-2）+ PTGES 产生 PGE2。
- 缺的一环：**人源、痛觉神经元、受体表达**。小鼠数据不能直接代替人（本项目撞车文献反复强调人鼠差异大）。
- 本轮目标：用真实的人 DRG 单核数据，逐簇量化"介质 → 受体 → 伤害感受器亚群"。

## 3. 主要结果（带数字）

### 3.1 关键事实：痛觉神经元自己不制造炎症，只负责接收

| 基因 | 在 DRG 神经元中的表达比例 | 含义 |
|---|---|---|
| **PTGS2（COX-2）** | **0.00%** | 神经元不造 PGE2 合成酶，PGE2 必须来自外周（肝/免疫细胞） |
| **IL1B** | **0.00%** | 神经元不造白介素-1β |
| **IL6** | 0.05% | 基本不造 |
| **TNF** | 数据集中无该基因记录 | 神经元不造肿瘤坏死因子 |
| PTGER3（接收 PGE2 的受体） | **32.93%** | 接收端却大量存在 |
| IL6ST（gp130） | 58.52% | IL-6 家族共用信号转导子广泛存在 |
| NTRK1（TrkA，接收 NGF） | 33.48% | 神经生长因子受体存在 |

这与已发表的独立结论一致：**COX-2 不在 DRG 神经元表达（COX-1 在）**，所以作用于神经元 EP 受体的 PGE2 来自外周，而不是神经元自产。

### 3.2 PGE2 受体：PTGER3（EP3）是绝对主力，PTGER1 几乎缺席

- **PTGER3 表达比例：15 簇平均 30.0%，最高 H3 达 83.9%**；在多个伤害感受器簇（H1 33.7%、H2 49.7%、H3 83.9%、H6 66.3%、H9 51.3%）都很高。
- **PTGER1 平均仅 0.1%（基本缺席）**；PTGER2 仅在非肽能簇 H10/H11 较高（9.4%/17.8%）；PTGER4 在 H3/H9/H2 中等（25–37%）。
- 交叉验证：Tavares-Ferreira 空间数据发现 **PTGER3 在 PENK+ 伤害感受器富集，并由其他多个伤害感受器亚群表达**，方向与我们一致（数据集/簇体系不同，不强行一一对应）。

### 3.3 其他介质受体与"下游放电机器"

- **TNF**：TNFRSF1A（TNFR1）平均 15.6%，H3 最高 36.5%；TNFRSF1B 普遍低。
- **IL-6**：特异受体 IL6R 低（平均 7.6%），但共用转导子 **IL6ST（gp130）平均 59.3%、最高 85.4%**——提示 IL-6 更可能经"反式信号"（可溶性 IL6R + gp130）作用。
- **IL-1β**：IL1R1/IL1RAP 偏低（最高 15–23%），属于稀疏接收。
- **OSMR**（IL-6 家族，抑瘤素 M/IL-31 受体亚基）：在非肽能簇 H10/H11 高达 79–82%。
- **下游离子通道**：SCN9A（Nav1.7）、SCN10A（Nav1.8）、SCN11A（Nav1.9）、TRPV1、TRPA1 在同一批伤害感受器簇共表达——受体收到的化学信号，有完整的"离子通道→动作电位"机器把它变成电信号和痛觉。

## 4. 这条桥怎么讲（"发信号—收信号"模型）

1. **发信号方（肝，前面已证实）**：炎症时免疫细胞制造 IL1B/TNF/IL6，PTGS2 通路制造 PGE2。
2. **信号传播**：介质经血液/组织液到达脊髓背根神经节。
3. **收信号方（本轮，人 DRG）**：伤害感受器带着匹配受体——尤其 **PTGER3 大量在痛觉神经元上**，外加 TNFR1、gp130、TrkA。
4. **变成痛**：受体激活后，同一神经元上的 Nav1.7/1.8/1.9、TRPV1、TRPA1 降低放电阈值、提高兴奋性，产生动作电位上传到脑，形成胁痛/痛觉敏化。

比喻：肝里的免疫细胞是"报警的人"，PGE2 这些是"报警短信"，DRG 伤害感受器上的受体是"手机"，离子通道是"响铃装置"。这一轮证明了**手机确实在、而且号码对得上**；但还没证明"我们的药把这条短信删掉了"。

## 5. 诚实的局限（不夸口）

1. **只证明"接得上"，不证明"药起作用"**：本数据集中没有药物处理，无法证明柴胡疏肝散/luteolin 改变了这些受体或通路。
2. **表达 ≠ 功能方向**：PTGER3 有多个剪接亚型、Gi 偶联，EP3 激动在部分情境下甚至可抗伤害（Tavares 引用的工作），转录组不能定 PGE2→EP3 的净效应方向，需电生理/功能实验。
3. **全部为正常捐献者、无炎症/疼痛对照**：不能看"疼痛态下受体是否上调"。
4. **单核测序有 dropout**：低比例（如 IL1R1）可能部分来自漏检，我们用"比例+均值"双指标呈现，不把零值绝对化。
5. **两套簇体系不同**：Nguyen（H1–H15）与 Tavares（1–12）只做方向性互证，不强行编号对应。
6. **受体丰度高 ≠ 该介质主导疼痛**：谁是主要驱动，仍需干预/拮抗实验。

## 6. 轮末五块回顾

### 6.1 这轮做了什么
- 在 CELLxGENE 定位并下载真实人 DRG 单核数据（Nguyen eLife 2021，1837 核/15 簇/6 供体）。
- 逐簇量化 38 个受体/通道/标志基因的表达比例与均值，产出 4 张 CSV + 1 张 300 dpi 点图。
- 确认"神经元不造炎症（PTGS2/IL1B 为 0）、只带受体（PTGER3 高）"的发信号—收信号结构。
- 用 Tavares-Ferreira 8 供体空间数据独立交叉验证 PTGER3 结论。

### 6.2 这轮没做什么
- 没有药物/干预对比，没有疼痛态 vs 正常态的受体变化。
- 未做受体的蛋白/电生理功能验证。
- 脚本与结果尚未同步进 `chaihu-nociceptive-mapping` 仓库（第 3 轮 MR 也还没同步）。

### 6.3 缺点
- 数据全为正常、无疾病对照，论证停在"解剖学/分子可接收"层面。
- EP3 功能方向不能由转录组定，存在解释张力。
- 单数据集、单测序平台，跨数据集只做了文献级互证而非重算。

### 6.4 下轮怎么补
- 把第 3、4 轮 MR/DRG 脚本与结果同步进仓库（manifest、checksums、docs 一起更新）。
- 进入防守项（#117）：多构象/多打分（GNINA/Smina）、MD 加长多种子、框架去循环、GSE344087 补全或 GSE298719 复现。
- 若要更强的"疼痛态"证据，检索是否有带慢性疼痛/炎症对照的人 DRG 数据可做差异对比。
