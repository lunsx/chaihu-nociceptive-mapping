# 人肝空间转录组：多切片重复分析报告（单切片 → 多切片）

日期：2026-11-14（夜班）。云主机 venv，脚本 `all_sections_analysis.py`。
目的：把原来"1 张 PSC 切片 + 1 张正常切片"的结论，升级为**同一供体多切片可重复、并加入多供体正常参考**，回答审稿人可能问的"单切片会不会只是偶然"。

## 一、数据构成（共 9 个文件）

| 组 | 供体 | 切片/文件 | 组织内 spot |
|---|---|---|---|

说明：
- 085648af 原直链返回 403，用内容一致的 `human_psc_visium.h5ad`（tissue uuid 9640a110）副本替换，已验证可正常打开。
- e84 是 Guilliams 实验室把 4 位正常供体合并的 pooled 文件，**没有保留图像坐标**，只能算 spot 比例/表达，不能算 Moran；它代表独立处理流程下的正常参考，不与 C73 直接合并。
- 每组（PSC、C73）只有 1 位供体，切片是**技术重复**，不是独立受试者，因此只做描述性统计、不做跨切片检验。

## 二、方法要点（与单切片口径一致，只改内存策略）

- 只取组织内 spot；用各自 raw 计数自做 lognorm（每 spot 库大小归一到 10,000 再 log1p）。
- Delaunay 邻接 + Moran's I，每基因 200 次置换。
- 为避免 7.9GB 内存被 OOM 杀死，改为 backed 读取、按 2,000 基因分块累加库大小、只把 29 个目标基因的小矩阵读进内存；实测峰值内存约 3.2GB（原全量读法峰值 7.8GB 被杀）。

## 三、核心结论

### 1. SPP1 的空间聚集在 PSC 四切片上全部成立，且与正常完全分开

Moran's I（越接近 1 越"成片聚集"）：

| 基因 | PSC 四切片 | C73 四切片 |
|---|---|---|
| SPP1 | 0.402 / 0.308 / 0.390 / 0.485 | 0.116 / 0.053 / 0.025 / 0.106 |
| FOS | 0.279 / 0.179 / 0.156 / 0.295 | 0.119 / 0.065 / 0.085 / 0.076 |

- SPP1：PSC 区间 0.31–0.49，C73 区间 0.03–0.12，**两组区间没有任何重叠**，说明"病变肝里 SPP1 成片聚集"不是单切片偶然。
- FOS：PSC 0.16–0.30，C73 0.07–0.12，方向一致但差距小于 SPP1。

### 2. 阳性 spot 比例同样可重复

- SPP1：PSC 29.3%–40.1% vs C73 1.7%–2.5%（约 15–20 倍）。
- FOS：PSC 23.6%–39.0% vs C73 9.6%–15.4%。

### 4. 稀疏炎症细胞因子仍无 spot 级聚集，与单切片结论一致

IL1B、TNF、PTGS2 等在四切片 Moran I 都接近 0——不是它们不表达，而是 Visium 每个 spot 混十几个细胞、把只在少数细胞表达的基因稀释到检测限。这一局限在单切片报告里已说明，多切片结果没有改变，正好说明单细胞与空间数据互补。

## 四、仍需如实保留的局限

- 疾病侧只有 PSC011 一位供体，多切片证明的是**技术重复性**，不能替代多位患者的独立重复；CELLxGENE 里没有第二个人类疾病 Visium 供体。
- 疾病是 PSC 不是脂肪性肝炎，不能外推为脂肪肝疾病特异结论。
- e84 多供体正常集无坐标，不能算 Moran，且处理流程不同，只作独立参考、不与 C73 合并。
- spot 多细胞混合，低计数按"检测受限"处理，不写成"确认缺失"。
- 空间数据不直接测痛，只刻画痛觉敏化相关分子的空间排布。
